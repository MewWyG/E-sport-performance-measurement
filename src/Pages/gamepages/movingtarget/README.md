# Moving Target Game

## Overview

`Moving Target` หรือ `เป้าเคลื่อนที่` เป็นเกมสำหรับทดสอบความเร็วในการตอบสนอง ความแม่นยำ การประสานงานระหว่างตากับมือ และความสามารถในการติดตามเป้าหมายที่กำลังเคลื่อนที่

เกมจะมีเป้าหมายจริงทั้งหมด `50 เป้า` ผู้เล่นต้องคลิกเป้าหมายจริงให้โดนก่อนที่เป้าจะเคลื่อนที่ครบระยะที่กำหนด หากคลิกโดน ระบบจะสร้างเป้าหมายจริงตัวถัดไปทันที เมื่อเป้าหมายจริงเกิดครบ 50 เป้า หรือผู้เล่นกดจบเกม ระบบจะแสดงผลลัพธ์

---

## How to Play

1. กดปุ่ม `เริ่มเล่น` เพื่อเริ่มเกม
2. ใช้เมาส์คลิกเป้าหมายจริงที่เคลื่อนที่อยู่บนสนามเล่น
3. หากคลิกโดนเป้าหมายจริง ระบบจะสร้างเป้าหมายใหม่ทันที
4. หากคลิกพื้นที่ว่าง หรือเป้าหมายเคลื่อนที่ครบระยะก่อนคลิก จะนับเป็น `พลาด`
5. ในบางโหมดจะมี `เป้าหลอก` ผู้เล่นต้องคลิกเฉพาะเป้าหมายจริง
6. หากคลิกเป้าหลอก จะนับเป็น `คลิกผิด`
7. เกมจะจบเมื่อเป้าหมายจริงเกิดครบ `50 เป้า` หรือผู้เล่นกด `จบเกม`
8. หลังจบเกม ระบบจะแสดงผล เช่น จำนวนยิงโดน จำนวนพลาด ความแม่นยำ เวลาเฉลี่ย และจำนวนคลิกผิด

## Difficulty by Mode

ความยากหลักของเกมขึ้นอยู่กับโหมดที่เลือก

| Mode | Target Size | Move Duration | Decoy Count |
|---|---:|---:|---:|
| Easy | ใหญ่ | ช้า | 0 |
| Normal | กลาง | ปานกลาง | 1 |
| Hard | เล็ก | เร็ว | 2 |

`Move Duration` คือเวลาประมาณที่เป้าใช้ในการเคลื่อนที่ครบ `movementStepDistance`  
ค่าน้อยลง = เป้าเคลื่อนที่เร็วขึ้น

## Controlled Distance System

เกมนี้ไม่ได้สุ่มระยะทั้งหมดแบบอิสระ แต่ใช้ระบบ `distance schedule` เพื่อควบคุมความยุติธรรมของแต่ละเป้า

แต่ละเป้าจะมีค่า 2 อย่าง:

```txt
movementStepDistance = ระยะที่เป้าต้องเคลื่อนที่ก่อนหาย
spawnDistance = ระยะจากจุดอ้างอิงไปยังจุดเกิดของเป้า
