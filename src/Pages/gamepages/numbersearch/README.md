# Number Search Game

## Overview

`Number Search` เป็นเกมค้นหาตัวเลขบนกระดานที่ต้องคลิกตัวเลขจากน้อยไปหามากตามลำดับ เกมจะมีหลายเลเวล และแต่ละเลเวลจะมีตัวเลขจำนวนเพิ่มขึ้นตามความยาก

เกมนี้ทดสอบความเร็วในการตอบสนอง ความสนใจในรายละเอียด และความสามารถในการมองหาตัวเลขที่ถูกต้องบนสนามเล่น

## How to Play

1. กดปุ่ม `เริ่มเล่น` เพื่อเริ่มเกม
2. ดูตัวเลขที่ปรากฏบนกระดาน
3. คลิกตัวเลขลำดับถัดไปที่น้อยที่สุดตามลำดับเริ่มจากค่าต่ำสุด
4. เมื่อคลิกถูก ตัวเลขจะถูกทำเครื่องหมายว่าผ่านแล้ว และผู้เล่นจะต้องหาเลขถัดไป
5. หากคลิกผิด ระบบจะนับเป็น `คลิกผิด` และคะแนนจะลดลง
6. เมื่อทำครบลำดับในเลเวลนั้น เกมจะขึ้นไปยังเลเวลถัดไป
7. เกมจะจบเมื่อเล่นถึงเลเวลสูงสุดหรือผู้เล่นหยุดเกม

## Scoring

- คลิกถูกจะได้คะแนนตามค่าที่กำหนดในเกม
- ทำเลเวลสำเร็จจะได้โบนัส
- คลิกผิดจะโดนหักคะแนน
- คะแนนรวมจะคำนวณจากจำนวนคลิกถูก เลเวลที่ผ่าน จำนวนคลิกผิด และเวลาเฉลี่ยในการค้นหา

## Level System

แต่ละเลเวลจะกำหนดจำนวนตัวเลขและขนาดกระดาน:

- เลเวลที่สูงขึ้นจะมีตัวเลขมากขึ้น
- กระดานจะวางตัวเลขโดยใช้ระบบวางแบบมีระยะห่าง เพื่อให้ผู้เล่นไม่คลิกผิดจากตำแหน่งที่ชิดกันเกินไป
- ระบบยังมี fallback หากวางตำแหน่งตามกฎไม่ได้ เพื่อให้เกมยังเล่นได้

## Notes

- เลเวลสูงสุดของเกมถูกกำหนดไว้ที่ `MAX_NUMBER_SEARCH_LEVEL`
- ฟังก์ชันคำนวณคะแนนจะใช้เวลาเฉลี่ยในการค้นหาและจำนวนคลิกผิดเป็นตัวแปรหลัก
- การวางตัวเลขในแต่ละเลเวลมีการพยายามจัดให้มีระยะห่างและมุมการเลี้ยวที่เหมาะสม
