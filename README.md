# SkillPulse

Vite + React project scaffolded manually for the workspace root.

## Setup

1. ติดตั้ง Node.js (แนะนำเวอร์ชัน 18 ขึ้นไป)
2. รัน `npm install`
3. รัน `npm run dev`

## สคริปต์

- `npm run dev` - เรียกใช้งานเซิร์ฟเวอร์ development
- `npm run build` - สร้าง build production
- `npm run preview` - พรีวิว build production
